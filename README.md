# Zuruf

Persönlicher Eingang für Aufgaben, Notizen und Belege: sprechen, tippen oder fotografieren.

Dieses Repository enthält nur die Oberfläche der App. Die Daten liegen in einer privaten Datenbank hinter einer
Anmeldung, die für andere gesperrt ist. In `config.js` stehen Projekt-Adresse und öffentlicher Schlüssel. Das ist so
vorgesehen: Die Zugriffsregeln der Datenbank schützen die Daten, nicht der Schlüssel.

Veröffentlicht mit GitHub Pages.
